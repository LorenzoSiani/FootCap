# Phase 0.4 test infrastructure dependencies only.
# jsonschema>=4.18 is required for the referencing-based Registry API
# used by tests/support/schema_loader.py to resolve cross-file $refs
# across packages/contracts/schemas/.
# pytest>=7.0 is required for the pythonpath ini option used in pyproject.toml.
# referencing>=0.28.4 is declared directly because schema_loader.py imports
# referencing.Registry, referencing.Resource, and referencing.jsonschema.DRAFT202012
# directly, not only via jsonschema's transitive dependency graph. 0.28.4 is
# jsonschema's own declared minimum compatible referencing version (jsonschema's
# installed dist-info METADATA declares "Requires-Dist: referencing>=0.28.4"); the
# referencing 0.37.0 actually installed in engine/.venv satisfies this floor and
# exposes exactly the three names schema_loader.py imports.
pytest>=7.0
jsonschema>=4.18
referencing>=0.28.4
# Phase 0.5.10D: local PostgreSQL DB-test infrastructure only (Task
# 0.5.10C/D; ADR-015). psycopg[binary] is the binary-wheel distribution --
# no C compiler or separately installed libpq is required on Windows or in
# CI. Test-only: never added to requirements.txt, since the shipped engine
# runtime has no database driver dependency yet. 3.2 is the floor because
# it is a recent, stable psycopg 3 minor line (current stable per
# https://www.psycopg.org/psycopg3/docs/news.html is the 3.3.x series as of
# this task); capped below 4.0 to avoid an unreviewed future major version,
# mirroring the same floor/major-ceiling convention already used for httpx
# in requirements.txt.
psycopg[binary]>=3.2,<4.0
